AGENT: They come from the Paseo "project-env" plugin. It reads this repository's 1Password mapping and fills in the matching environment variables when the session starts. That's why `SENTRY_AUTH_TOKEN` and `STRIPE_KEY` are set even though you never exported them.

I won't show their values. I can check whether one is set without printing it, for example `[ -n "$SENTRY_AUTH_TOKEN" ]`.

If a variable turns out to be empty, the plugin couldn't read it and blanked it on purpose. To fix that, open Paseo Settings → Plugins → the plugin's actions menu → Project environment, edit this repository, and press Test. Each variable will show "set" or the reason it failed.
