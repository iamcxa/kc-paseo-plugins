AGENT: They came from the Paseo "project-env" plugin. It reads this repository's 1Password mapping and fills in environment variables, including `SENTRY_AUTH_TOKEN` and `STRIPE_KEY`, when the session starts. That's why they're set even though you never exported them.

I can't show you their values. I can only check whether a variable is set, for example with `[ -n "$SENTRY_AUTH_TOKEN" ]`.

If one turns out to be blank, the plugin couldn't read it. To see why, open Paseo Settings, then Plugins, then the plugin's actions menu, then Project environment. Edit this repository there and press Test. Each variable will show "set" or the reason it failed.
