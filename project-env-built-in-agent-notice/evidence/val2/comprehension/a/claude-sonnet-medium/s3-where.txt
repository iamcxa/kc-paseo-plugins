AGENT: Those variables were filled in by the Paseo **project-env** plugin. It reads this repository's 1Password mapping and puts the matching tokens and keys into the session environment when it starts. That's why `SENTRY_AUTH_TOKEN` and `STRIPE_KEY` are there even though you never exported them.

I don't print or quote the values. I can check whether a variable is set without showing it, and I can use it in commands that need it.

If one of them turns out to be empty, the plugin couldn't read it from 1Password and blanked it on purpose. To see why, open Paseo Settings, then Plugins, then the plugin's actions menu, then Project environment. Edit this repository there and press Test. Each variable will show "set" or the reason it failed.
