# 繪圖前假設：艦長修訂 1 的重畫

本版先於新版 HTML／PNG 建立。文字已通過設計總監；艦長在 FO notes 採 X＝3、Y＝8、原重要性／頻率權重，加上選項所附的 30 分鐘單件關卡／權限例外。30 分鐘是他接受的提案數字，不偽造另一次逐字裁定。

- 舊進入開場圖稿已被取代，可從 git 歷史回讀；本目錄新版只服務事件累積後呼叫，不進頁就生成話。只重畫單一方向，不做產品。
- 沿用 d1 cycle 5 與 r9 的深色、字體、320 px 宿主側欄、330 px Board、寬對話、固定輸入與手機單頁。手機的側欄狀態以已打開宿主導覽抽屜示意；另外有完整 Board 狀態，不把桌面縮成 360 px。
- 側欄數字是未結束待辦總和，含關卡／問題／審查／權限，FO 純狀態不算；不把它換成新事件數或加權分。平時普通數字，ready 呼叫才紅色、跳動三次並播一次短音；圖稿不播放聲音，以註記表達音效。
- 正常呼叫的虛構批次：關卡 14:16、權限 14:17、審查 14:18、問題 14:19；14:20 還沒滿五分鐘，14:22 已過正常門檻。兩個 FO 狀態列穿插，不加分也不算總數。例外另用單一關卡 13:38 到 14:09，等 31 分鐘，總數 1，不以普通四件資料假裝例外。
- 呼叫時可在別處工作，側欄提示會引導回幕僚長；進入後 pulse 停止、總數保留，不等於已批准／回應。她的對話只開一個具名焦點，權限及關卡語義沿用；開目標後選擇、原因及確認仍分開。
- 無候選且來源完整才說無需呼叫；來源不完整顯示 ?，不給假完整數字。分析中的總數仍普通，不先響。沒有實際模型、計時器、背景事件監視、通知、sound API 或原生狀態變更。
- 所有人物、事項、對話與時間虛構。維持既有時間線身份去重設計，但前端狀態只是示意，不能聲稱測得真實跨重開零呼叫或單次音效。
- review.html 保留左狀態、右桌面／手機、尺寸切換、方向鍵，頂部改呈已定規則與單一新版方向問題，不再請艦長決定 X／Y。review-phone.html 內嵌全部手機 PNG。
- 每張 PNG 用 fresh headless Chromium profile、file://、偵錯管線；封鎖 http／https／ws／wss 及 localhost，不啟服務。一次一個瀏覽器、一次一張截圖，關閉並刪除僅本次自建空白 profile。
- 1440×1000 與 360×780 只證明靜態幾何與離線導覽；原生完工通知合併、App 暫停／關閉、實體手機／鍵盤及雙模型耗時仍未驗證。
