# kc-paseo-plugins

Paseo plugins by Kent. Install one with `paseo plugin add git:iamcxa/kc-paseo-plugins:<plugin>`.

- `project-env`: per-project environment variables from 1Password, with a built-in notice telling each new agent where they come from. [Introduction](docs/project-env/index.md).
- `spacedock-bridge`: a Paseo screen and panel for running Spacedock first officers: decisions, review requests, a comms officer chat and a fleet board. [Source and overview](https://github.com/iamcxa/kc-paseo-plugins/tree/main/spacedock-bridge).
