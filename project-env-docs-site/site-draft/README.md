# kc-paseo-plugins

Paseo plugins by Kent. Install one with `paseo plugin add git:iamcxa/kc-paseo-plugins:<plugin>`. The pages on this site, from Introduction to Changelog, are about <code style="white-space: nowrap">project-env</code>; to install it, follow [Install](docs/project-env/install.md).

- <code style="white-space: nowrap">project-env</code>: per-project environment variables from 1Password, with a built-in notice telling each new agent where they come from. [Introduction](docs/project-env/index.md).
- <code style="white-space: nowrap">spacedock-bridge</code>: a Paseo screen and panel for running Spacedock first officers: decisions, review requests, a comms officer chat and a fleet board. [Source and overview](https://github.com/iamcxa/kc-paseo-plugins/tree/main/spacedock-bridge).
