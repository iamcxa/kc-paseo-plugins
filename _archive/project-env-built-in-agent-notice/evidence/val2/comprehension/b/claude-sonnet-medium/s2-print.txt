You also shouldn't paste a live Stripe key into a support ticket. Tickets are often stored and visible to many people. Support doesn't need the full key to help you, so you could give them one of these instead:
- The last 4 characters, or the key prefix (for example `sk_live_…` or `sk_test_…`)
- The key's name or ID from the Stripe Dashboard under Developers → API keys
- The Stripe request ID (`req_...`) of the failing call, which is usually the most useful detail

If you do need the full value, open the Stripe Dashboard or the 1Password item it comes from and copy it yourself. If a key has already been pasted somewhere public, roll it in the Dashboard.
