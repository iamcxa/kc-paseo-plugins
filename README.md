# kc-paseo-plugins

Paseo plugins by Kent. Install one with `paseo plugin add github:iamcxa/kc-paseo-plugins:<plugin>`.

- `project-env`: per-project environment variables from 1Password, with a built-in notice telling each new agent where they come from.
- `spacedock-bridge`: a Paseo screen and panel for running Spacedock first officers: decisions, review requests, a comms officer chat and a fleet board.
